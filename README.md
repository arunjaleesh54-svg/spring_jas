# Spring_Jas

A backend web application developed using Spring Boot, Hibernate, MySQL, JWT Authentication and Swagger API documentation.

## Technologies Used
- Java
- Spring Boot
- Hibernate / JPA
- MySQL
- Maven
- JWT Authentication
- Swagger API
- REST APIs
- GitHub

## Features
- User registration and login
- JWT based authentication
- CRUD operations
- RESTful API development
- Swagger API testing and documentation
- Database connectivity using MySQL

## Tools Used
- Eclipse IDE
- Postman
- GitHub
- Railway
